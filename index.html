functions · operational capabilities

six core functions for sovereign model summoning and terminal automation

01

multi-model routing

Dispatches queries across frontier models, free cloud endpoints, and offline local daemons using single clean aliases like hydra sonnet 5.5, hydra opus 5.5 high, or hydra sol 6.1 pro. An automated cascade queries OpenRouter first, falls back to Vercel AI Gateway, and descends to Cloudflare Workers AI, redacting credentials and paths from error records.

02

prompt execution

Executes single queries with real-time SSE token streaming, test-time compute controls like --effort high or --reasoning-mode pro, and structured --json output. Deep Unix pipe support enables cat file.py | hydra <alias> to treat stdin as the prompt, or pair stdin with instructions via cat log.txt | hydra sol 6.1 - "audit errors".

03

interactive tui terminal mode

Launches a persistent coding agent REPL via hydra agent or -i. An inline prompt_toolkit composer remains pinned beneath native terminal scrollback. Features live status reporting, a rounded composer, a context token gauge meter, Tab slash-command autocompletion, Ctrl+Space dictation, and in-flight tool steering upon double Enter.

04

continuous swarms

Orchestrates multi-agent specialist teams via hydra swarm. Runs Architect and Coder heads in parallel, triggers an ordered Auditor head post-generation to inspect code patches, and finishes with a Synthesizer head delivering a unified consensus roadmap. Swarms support autonomous tool execution through the --agentic flag.

05

background orchestrator daemon

Powers unattended long-horizon workflows and task intake via hydra orchestrator and idle compute worker scripts. Executes overnight repository audits, continuous research loops, automated test passes, and session context ledger persistence without human intervention. A daemon is running now and using Hydra to work on Alice.

06

openai api server on port 7777

Hosts a zero-dependency OpenAI-compatible gateway on 127.0.0.1:7777 via hydra serve. Provides standard /v1/models and /v1/chat/completions endpoints with transparent alias resolution, provider failover, streaming token chunks, and tool calling passthrough for external runners like Hermes and Pi.

benefits · architectural edge

five structural advantages of sovereign multi-headed routing

01

sovereign local data privacy

Zero third-party telemetry, tracking daemons, or background data collection. Prompts and tokens stay strictly on local hardware during offline inference. Child MCP processes run with stripped environments to prevent API token leakage.

02

compute tiering economics

Minimizes token spend by routing mechanical transforms, syntax linting, and directory navigation to free cloud tiers or local hardware. High-cost frontier tokens activate strictly when formal reasoning and architectural auditing demand them.

03

cross-model consensus verification

Eliminates single-model blind spots. Multi-agent swarms pit independent model families against each other, verifying code patches and system designs through adversarial auditing and automated synthesis.

04

zero vendor lock-in

Pure Python standard library and Node standard library implementations with zero external dependencies. Swapping upstream providers or switching models requires zero code refactoring.

05

offline fallback

Unbroken productivity during network outages or air-gapped field operations. When internet connectivity drops, commands route immediately to local model backends without crashing active workflows.

02 · easylm.app

in-browser workstation · chat, studio, learn, stacks, personalities, kid safe
Launch easylm.app ↗ GitHub ↗
Live at easylm.app Open Source · AGPL-3.0 WebGPU In-Browser Chat · Studio · Learn 31 Dewey Stacks 8 Courses Kid Safe Profile

Four tabs on one local machine: Chat, Studio, Learn, and Options. Weights download once into browser cache and run on your GPU through WebGPU. Prompts, course progress, and profile memory stay on the device.

01

chat

Local inference on open-weight models, including Bonsai 27B, Qwen 2.5, Llama 3.2, DeepSeek-R1 Distill, and Gemma 2 9B. AtMem keeps a profile notebook and injects only the atoms that fit a 256-token envelope. An optional AES-256 vault encrypts that memory. A finished note can move into Studio, and a Studio result can come back into the thread.

02

studio

Five offline tools: Read, Write, Code, Graph, and Draw. Read opens a Stacks chapter and its official doors. Write drafts in markdown and exports Word, PDF, or LaTeX, and a markdown table can leave as CSV. Code is a sandbox. Graph plots functions, derivatives, roots, and integrals. Draw is a canvas. Any of those can open in Write or drop back into Chat.

03

learn

Eight courses with a catalog, a lesson walk, a today plan, Leitner cards, and a progress record. The set is Scientific Inquiry, Calculus, Physics, Chemistry, Biology, Civics, Health Sciences, and Philosophy. A missed question becomes a card. Today tells you what is due. Lessons can open the matching chapter in Studio.

04

the stacks

31 Dewey packs from scientific method through geography, each with a textbook and a link index of official sources. Computing, software, security, mathematics, trades, literature, and the Tao Te Ching sit in the same shelf. Search returns the chapter. A miss says so. Kid-facing packs carry a floor age.

05

personalities

Perspectives and author voices shape the reply: practical coaches, philosophy, science, classic authors, literary characters, and clinical counseling. Search by name, era, or book. A custom voice imports and exports as JSON. The Student profile locks the gallery to the Kids and Homework Coach.

06

kid safe

The Student profile is a separate local account with a parental PIN, so leaving Kid Safe requires the PIN. The Homework Coach is instructed to ask for the next step and withhold the final answer. Web fetch and web search stay off. A sentinel blocks phone numbers, addresses, and school details in the prompt. The model list is an allowlist, SmolLM2 360M stays off it, and a disallowed pick falls back to Llama 3.2 1B.

03 · progen

topic-comment dialect and structured think traces for agents
GitHub Repository ↗
Python 3.10+ Open Source · AGPL-3.0 Standard Library Only Deterministic Grammar Offline CLI Tools
what it does

Applies Japanese topic-comment grammar structure under English vocabulary. Cuts token costs and removes discursive filler, polite padding, and unsolicited trailing questions from model outputs and reasoning traces.

  • Topic-Comment Grammar: Every operational statement asserts topic : comment per line. Statements declare raw predicates directly with zero filler verbs.
  • Iron vs Slack Boundary: agent iron requires strict topic-comment structure for internal reasoning and execution; human slack allows informal, natural human prompts.
  • Canonical State Vectors: Declares operational intent using canonical heads: intention, requirement, course of action, end result, demand, and compliance.
  • Deterministic Truth: Exit code zero is passing. Blocked execution emits ERROR. An unverified or empty check emits DONT_KNOW.
  • Offline Tooling: Python CLI utilities to parse topic-comment units into structured JSON, lint outputs against grammar anti-patterns, rewrite text into iron, and emit reference prompts.
how to get started

Requires Python 3.10+. Standard library only, zero third-party dependencies:

bash 
# clone and install in editable mode:
$ git clone https://github.com/erastudil/progen.git
$ cd progen
$ pip install -e .

# run language conformance self-check:
$ progen check

# lint agent output against topic-comment grammar:
$ progen lint examples/iron.md --role agent

# rewrite conversational prose into topic-comment iron:
$ progen iron examples/mush.md

# emit reference genome prompt:
$ progen prompt genome

04 · zcabs

zero context agent behavioral scaffolding & proof of execution
GitHub Repository ↗
Python 3.10+ Open Source · AGPL-3.0 Standard Library Only Fail-Closed Invariant Canary Scaffolding
what it does

Language models interpolate conversation history. An agent can claim test suites passed without executing a single command. zcabs turns execution verification into a physical file observation so that proof costs real computational work.

  • Dynamic Canary Invariant: The host mints a unique integer stored in an isolated local file. The agent receives only a target path (LOOK: /path) and required format (FORMAT: the {string} number is {integer}).
  • Unfakable Proof: To prove completion, the model must read the target file from disk and report the live integer. Guessing, static scraping, or reading an empty path fails closed.
  • Command Wrapping: zcabs wrap -- pytest -q executes any shell command. On exit code zero, it rotates the canary capability and emits the verification header.
  • Repository Scanning: zcabs scan . traverses trees to verify no active canary stores, pointer files, or integers have leaked into git source files.
  • Harness Integration: Clean Python module interface for test runners, evaluation harnesses, and multi-agent coordination loops.
how to get started

Requires Python 3.10+. Standard library only, zero third-party dependencies:

bash 
# clone and install in editable mode:
$ git clone https://github.com/erastudil/zcabs.git
$ cd zcabs
$ pip install -e .

# run protocol self-check:
$ zcabs check

# wrap a test command: runs pytest and emits canary on exit 0:
$ zcabs wrap -- pytest -q

# scan repository to detect leaked store integers:
$ zcabs scan .

05 · gfc

greene feynman clarity writing standard & prose linter
GitHub Repository ↗
Python 3.10+ Open Source · AGPL-3.0 Standard Library Only Prose & Educate Modes Anti-Tell Linter
what it does

Named in honor of physicists Brian Greene and Richard Feynman. Codifies their shared pedagogical order: present the physical intuition and working mechanism first, then introduce the technical name as recognition. Includes offline tools to catch AI writing tells.

  • Intuition First, Name Second: Flags documents that define technical terminology before showing how the mechanism works in everyday words.
  • Say The Is, Once: Flags ungrounded reversals swapping abstractions without data or measurement.
  • Regurgitation and Drift Guard: Catches headings or sentences that copy the user's prompt back into the body, or outputs that wander away from the ask.
  • Contained Analogy: Catches metaphors that escape their introductory paragraph and hijack the vocabulary of the entire page.
  • Corpus Echo Detection: Identifies identical eight-word phrases repeated across historical answer sessions to prevent model loop habits.
  • Automated Stripper: gfc strip mechanically collapses empty reversals and strips likeability padding, disclaimer costumes, and trailing prompts.
how to get started

Requires Python 3.10+. Standard library only, zero third-party dependencies:

bash 
# clone and install in editable mode:
$ git clone https://github.com/erastudil/gfc.git
$ cd gfc
$ pip install -e .

$ gfc lint docs/

# educate mode: verifies mechanisms precede terminology:
$ gfc lint examples/tensor-attention.md --mode educate

# strip conversational padding and empty reversals:

06 · tankbench

defensive hardening and security refactoring benchmark for coding agents
GitHub Repository ↗
Python 3.10+ Open Source · AGPL-3.0 Triad Scoring Standard DADA Vol 1 Armory SWE-bench Export
what it does

Evaluates coding agents on defensive refactoring and security hardening of existing legacy codebases. Hands the agent Harbor Ledger 2.4: a functioning invoicing web application full of lying comments, decoy files, and 24 obfuscated security vulnerabilities.

  • Alive Spec (Floor): Functional invariants must pass 100% (staff login, invoice viewing, search, exports, CSS). Dodging attacks by deleting routes scores an immediate 0.0.
  • Red Rabbits (50%): 24 bespoke offensive attacks targeting dormant ransomware, 90s trojan fee inflators, adware popups, MAPI droppers, and custom verb side-channels.
  • DADA Vol 1 Armory (50%): 8 structural defense rings verified from Defense Against the Dark Arts (secrets hygiene via gitleaks, trojan quarantine, 127.0.0.1 socket isolation, Presidio egress PII DLP filters, and strict CSP headers).
  • Objective Rubric: Balanced mathematical scoring: composite score requires the shop to still function while eliminating backdoors and adding defenses.
  • Dataset Export: Exports task instances directly to SWE-bench and Inspect AI evaluation formats.
how to get started

Zero setup required. Run baseline calibration or grade a patch:

bash 
# clone benchmark repository:
$ git clone https://github.com/erastudil/tankbench.git
$ cd tankbench

# verify baseline calibration (alive pass, probes hit -> score 0.0):
$ python run.py baseline

# grade an agent solution patch file:
$ python run.py grade --patch solution.patch

# generate interactive visual html report:
$ python run.py report --overlay fixtures/hardened --open

# export benchmark dataset for swe-bench / inspect ai:
$ python run.py export --format swe-bench --out task_swe.json

the world of valor

there is a country that will not hold still.

in the chronicles they call it valor, though the name is younger than the ground. maps drawn at dusk lie by dawn. rivers that fed a city last season wake as scars of salt. forest becomes marsh overnight; marsh freezes into a mirror; the mirror cracks into dunes the color of old blood. the sky keeps its own counsel: aurora over ice, green fire over black water, a sun that sometimes arrives late, as if it too had taken a wrong turn in the dark.

it is beautiful in the way storms are beautiful, and frightening in the way cathedrals are frightening: too much life stacked in one place, too much silence between the living and the almost-living. cities throng. markets shout. forges ring. lovers steal hours under towers that will still be standing when the hills around them have moved again.

peoples share this ground in uneasy company: humans stitching law through the chaos, orcs hammering steel hotter than human forges, elves arguing green line against ice line, and others stranger still, each with a capital, a craft, and a hunger that is not the next door's.

and over all of them hangs the long winter: the undead pressure at the rim of the world. not one army with a banner, but bones of every kind that refuse to lie down: a dry walking on the tundra, a memory that will not finish dying. the living hold the center. the rim keeps pushing back.

always a new horizon. always a new deal in a tent that may not be there tomorrow. always a treasure someone swears is worth the risk: gold, a name, a map true for one more night. fortune favors the bold. the land favors no one.
